# Heyy , I'm Aat💙

This GitHub is my learning journal.

Every repository represents something I wanted to understand, build, or improve. Some projects are experiments, some are complete applications, and some are simply ideas I wanted to bring to life.

I started with Python and machine learning, but somewhere along the way I realized I enjoy creating complete applications just as much as training models. I like the process of turning an idea into something people can actually use, even if it means spending hours debugging, redesigning, and learning from mistakes.

To me, every project is more than just code—it's a story of something I didn't know yesterday but understand a little better today.

---

## What I'm Exploring

Machine Learning & Deep Learning
Large Language Models (LLMs)
Retrieval-Augmented Generation (RAG)
AI Agents & Agentic Workflows
Python & Backend Development
Building AI applications that solve real problems
